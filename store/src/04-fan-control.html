Fan & pump control

Drag a fan speed

Bind the built-in Slider to any sensor with a software control. No plugin-specific widget is involved.

1

Any controllable fan

A fan or pump the hardware library can drive becomes a writable variable, marked controllable.

2

Write on release

The track takes its range from the chip; the write happens when you let go, and the slider settles on what the chip accepted.

3

Hand it back

The Restore fan control action returns one fan to the motherboard's curve; Restore all fans does it for every controllable fan.

4

On by default

Fans are handed back when Macro Deck stops, so a speed set once cannot outlive the plugin by accident.

Set fan speed Restore fan control Restore all fans

Fan control requires PawnIO and administrator rights. Every other sensor works without them.
